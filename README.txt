PilotLog Airline v4.5

Includes logbook, calendar import, totals, trips/layover, LogTen export and Payroll.
Payroll rates are editable in-app and stored locally. EUR/MAD is indicative: current month uses a live rate until day 30; on/after day 30 the app stores the rate for that month and never changes it. Historical months fetch day 30 (falling back to the latest previous available day).

Upload index.html, app.js, styles.css, manifest.webmanifest and sw.js to the root of the GitHub Pages repository.
